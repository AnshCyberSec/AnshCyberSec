## About

I'm a Java backend engineer focused on building backend systems that are correct under load and hard to break into — not just systems that pass a demo. My core work is in Spring Boot: REST APIs, service-to-service communication, data modeling with JPA/Hibernate, and caching with Redis. Alongside development, I approach every system with a security-oriented mindset — thinking through authentication, authorization, and attack surface as part of the design, not as an afterthought.

I'm early in my career, currently completing my B.Tech in Computer Science and transitioning from internship-scale backend work into full-time engineering roles. What I bring is depth on a focused stack rather than breadth across many — and a habit of understanding a system fully before I ship it.

## Security Focus

**Build systems → Understand attack surfaces → Secure applications**

Working on the implementation side of authentication and authorization gives me a grounded view of how these systems actually fail — not just how they're supposed to work. My security interest centers on:

- Web application security fundamentals
- Authentication & authorization design (JWT, session handling, RBAC)
- IAM fundamentals and access-control modeling
- Secure API development practices
- Vulnerability-oriented thinking when reviewing my own backend code

This isn't presented as professional security experience — it's a lens I apply as a developer who wants to understand what I'm defending before I ship it.
