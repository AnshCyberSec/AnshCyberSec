## About

I'm a Java backend developer focused on designing and building reliable, secure server-side systems — REST APIs, microservices, and the infrastructure that keeps them fast and safe. My work spans Spring Boot service development, Kafka-based event-driven architecture, Redis caching, and Spring Security-based authentication and authorization.

Alongside backend engineering, I have a strong interest in application security — I study how systems are attacked so I can build ones that hold up. I approach security from the inside out: understanding the code, the data flow, and the failure points before reasoning about how they could be exploited.

**Build → Secure → Scale**

## Featured Projects

### E-Commerce Microservices Platform
[`github.com/AnshCyberSec/ecommerce-microservices`](https://github.com/AnshCyberSec/ecommerce-microservices)

An event-driven e-commerce backend built as 4+ independently deployable services — Product, Inventory, Order, and Notification — communicating asynchronously over Apache Kafka.

- Spring Cloud with Eureka Service Discovery and a central API Gateway for routing
- OpenFeign for inter-service REST calls, backed by Resilience4j circuit breakers for fault tolerance
- Real-time email notifications triggered through the Notification Service
- 10+ REST APIs with pagination and sorting across modules

`Spring Boot` `Spring Cloud` `Kafka` `Docker` `MySQL` `OpenFeign` `Resilience4j`

<br/>

### Hospital Management System
[`github.com/AnshCyberSec`](https://github.com/AnshCyberSec)

A REST API backend for managing hospital operations across four distinct roles, with security enforced at every layer.

- JWT-based authentication and Role-Based Access Control across ADMIN, DOCTOR, RECEPTIONIST, and PATIENT roles
- BCrypt password hashing and a clean Controller / Service / Repository / DTO / Mapper layered structure
- 20+ REST APIs covering appointment lifecycle management, duplicate slot prevention, and soft delete
- Centralized exception handling with custom exceptions for consistent API error responses

`Spring Boot` `Spring Security` `JWT` `RBAC` `JPA/Hibernate` `MySQL`

<br/>

### Enterprise Java Backend Applications
[`github.com/AnshCyberSec`](https://github.com/AnshCyberSec)

A collection of 8+ independent backend systems — including TaskFlow, Employee Management, Banking Management, and a JWT Authentication System — totaling 50+ REST APIs.

- Spring Security, JWT, and Redis-backed refresh tokens across projects

`Spring Boot` `MySQL` `PostgreSQL` `Redis` `Spring Security`

- Authentication & authorization design — JWT, RBAC, IAM fundamentals
- A development background that helps me reason about application internals before evaluating how they could be attacked
- Ongoing study of penetration testing and vulnerability-oriented thinking
